# Kompetencematrix downloadpakke

Denne mappe indeholder en Excel-klar downloadpakke til kompetence- og kursusstyring.

## Filer

- `01_kompetencematrix.csv` — kompetencematrix med medarbejdere og proceskompetencer
- `02_kursusmatrix.csv` — kursusmatrix med status, datoer og kommentarer
- `03_niveau-forklaring.csv` — forklaring på kompetenceniveauer 0-5
- `04_kursusstatus-forklaring.csv` — forklaring på kursusstatus

## Sådan bruges filerne

1. Åbn CSV-filerne i Excel.
2. Gem evt. som `.xlsx` via **Filer → Gem som**.
3. Brug betinget formatering til farvekoder.

## Anbefalet opsætning i Excel

### Kompetencematrix
- 1 = Rød
- 2 = Grøn
- 3 = Blå
- 4 = Sort fyld + hvid tekst
- 5 = Gul

### Kursusmatrix
- Ja = Grøn
- Nej = Ingen farve eller lys grå
- Planlagt = Gul
- Udløbet = Orange/rød
- Ikke relevant = Grå

## Bemærkning

CSV-filerne bruger semikolon (`;`) som separator, hvilket normalt passer bedst til dansk Excel.
